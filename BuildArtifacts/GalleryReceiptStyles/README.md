# Receipt-style gallery comparison

Synthetic assets only. The before and after pages use the same six photograph assets and original receipt assets. No customer photograph or live gallery token is included. Receipt gradients are layout fixtures, not examples of the production receipt artwork.

`before` is the existing schema-v2 two-card presentation. `after` is schema v3 with Share-Friendly selected. Each width has a hero capture and Receipt Copy capture. Cards stack below 400px as before; the only added visible controls are the style selector and, when applicable, the QR privacy note.
